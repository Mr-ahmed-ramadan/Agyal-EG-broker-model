4. Test coverage

  • About 96 API unit tests (ledger rules, pricing, economics, order state, income, cash, onboarding rules, OTP, compliance flags, audit, documents) and 7 FIX gateway tests.
  • One end-to-end test that runs the whole flow against a fresh database: onboarding, compliance, deposit, quote, order, fill, settlement, coupon, withdrawal, flags, audit log and tracked documents.
  • Browser checks of the four apps on phone and desktop widths.

5. Phase map

  1. Phase 1 — Demo & sell (done). Hosted demo, branded prospect demos, economics, client experience, monitoring and audit, partnership documents.
  2. Phase 2 — Pilot readiness. Holiday calendar, tax sign-off, real SMS, deposit statement import, KMS, alerting, security review, broker legal documents.
  3. Phase 3 — First live broker. FIX certification with 1–2 banks, production eKYC/AML, custodian reconciliation, invited clients, daily operations per the SOP.
  4. Phase 4 — Scale. More banks and brokers, regulatory reporting packs, recurring plans, mobile apps, disaster recovery.
